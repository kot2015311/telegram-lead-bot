# Telegram Lead Generator Bot

Профессиональный Telegram-бот для автоматического сбора заявок от клиентов с сохранением в базу данных и уведомлением администратора.

## 🚀 Возможности
- 📱 **Интерактивное меню**: Удобные Reply-клавиатуры.
- 📋 **Пошаговая анкета (FSM)**: Сбор информации (услуга, имя, контакт).
- ❌ **Отмена анкеты**: Возможность сбросить ввод на любом шаге.
- 💾 **База данных SQLite**: Автоматическое сохранение всех заявок с датой и Telegram ID.
- 🔔 **Уведомление админа**: Мгновенная отправка карточки лида в личные сообщения администратора.
- 🔒 **Безопасность**: Токены и приватные ID вынесены в переменные окружения (`.env`).

## 🛠 Стек технологий
- **Python 3.12**
- **aiogram 3.x** (Async Telegram Bot API)
- **aiosqlite** (Async SQLite)
- **python-dotenv**
